# Shopify Order Analytics & Delivery Performance Tracker

## Overview
Analyzed Shopify order data to uncover city-wise sales patterns and 
delivery performance, using Power BI and Tableau to turn raw order 
exports into actionable dashboards.

## Tools Used
- Power BI (DAX measures)
- Tableau (calculated fields, LOD expressions)
- Excel

## What I Did
- Cleaned and standardized raw Shopify order export data (duplicates, 
  city/state mismatches, missing values)
- Analyzed order volume, average order value, and repeat-purchase rate by city
- Calculated average delivery velocity (order-to-delivery time) across cities
- Built a Power BI dashboard tracking city-wise sales, delayed-shipment 
  rate, and coverage gaps
- Visualized order trends and delivery coverage in Tableau to flag 
  underserved regions
